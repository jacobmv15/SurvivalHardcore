# SurvivalHardcore

SurvivalHardcore es un juego de tipo survival desarrollado en Unity como **proyecto de fin de grado superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**. El objetivo principal del proyecto ha sido aplicar los conocimientos adquiridos durante el ciclo, especialmente en programación con C# y uso del motor Unity.

---

## Descripción del proyecto

El proyecto consiste en un juego de supervivencia en el que el jugador debe mantenerse con vida el mayor tiempo posible frente a distintos desafíos.  
Durante el desarrollo se han trabajado aspectos como la lógica del jugador, comportamiento de enemigos y mecánicas básicas de juego.

El proyecto no está completamente terminado ni pulido como un producto comercial, pero cumple su función como trabajo final y demuestra el aprendizaje realizado.

## Estado del proyecto y aclaración sobre los commits

Este proyecto se encuentra en un estado incompleto.  
El historial de commits del repositorio no sigue una estructura profesional porque:

- Estaba aprendiendo a utilizar Git y GitHub mientras desarrollaba el proyecto.
- El tiempo disponible para el trabajo fue limitado, por lo que se priorizó el desarrollo del juego frente a la organización del repositorio.
- Muchos cambios se subieron de forma rápida para no perder avances.

Además, **el juego no está subido al completo al repositorio**, ya que al tratarse de commits muy grandes, GitHub no me permitía subir todo el contenido correctamente.
